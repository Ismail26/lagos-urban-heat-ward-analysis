# Satellite-image panels

The four corridor-composite cells expect the following files in this directory:

- `Oshodi-Ikeja GRA2.png`
- `Ajeromi-Apapa Satellite Imagery.png`
- `Abule Oja - Makoko2.png`
- `Obalende-Ikoyi Satellite Imagery2.png`

These large third-party satellite-image panels are not redistributed through GitHub. Users with permission to use them may place local copies here. The final composite outputs are provided in `figures/`.
